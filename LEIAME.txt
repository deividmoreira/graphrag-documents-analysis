# GraphRAG Contract Analyzer

## Ambiente de desenvolvimento com Conda

```
conda create --name graphrag-contracts python=3.12
conda activate graphrag-contracts
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Variáveis de ambiente

Crie um arquivo `.streamlit/secrets.toml` na raiz do projeto contendo:

```
[general]
API_KEY = "sua-chave-da-openai"
```

## Execução

```
streamlit run app.py
```

## Exemplos de perguntas

- Qual é o objeto principal do contrato?
- Quais são as obrigações das partes envolvidas?
- Existe multa prevista em caso de rescisão? Qual o valor?

## Manutenção do ambiente

```
conda deactivate
conda remove --name graphrag-contracts --all
```
