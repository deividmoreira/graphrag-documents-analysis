# GraphRAG Contract Analyzer

## Conda development environment

```
conda create --name graphrag-contracts python=3.12
conda activate graphrag-contracts
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Environment variables

Create a `.streamlit/secrets.toml` file at the project root with:

```
[general]
API_KEY = "your-openai-api-key"
```

## Running the app

```
streamlit run app.py
```

## Sample questions

- What is the primary object of the contract?
- What are the obligations for each party?
- Is there a penalty for breach of contract? If so, what is the amount?

## Environment maintenance

```
conda deactivate
conda remove --name graphrag-contracts --all
```
